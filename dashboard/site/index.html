How comparisons are calculated

Charts show measured medians. Metal-relative values compare the same device, workload, parameters, mode, queue depth and metric. Values above 1× favor Linux. The ratios invert metrics such as latency, where lower is better.

Driver builds, operating systems and run conditions vary. OpenGL workloads appear alongside Metal when matching measurements exist. See the run records for the exact source of each series.
